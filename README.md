## AsurePlayerSync

Плагин, реализующий синхронизацию различных данных между серверами посредством создания общей базы данных с информацией об игроках.
Позволяет сохранять содержимое инвентаря, эндер-сундука и уровень опыта.\
Плагин находится в состоянии доработки и может не подходить для релизных проектов.

---

## Модули и возможности

- **Сохранение данных**: При выходе игрока с сервера сохраняет некоторые его данные (содержимое инвентаря, эндер-сундука и уровень опыта) в базу данных MySQL.
При входе указанные данные игрока загружаются из базы данных, обеспечивая синхронизацию. Подобная концепция позволяет игроку
иметь общие данные на разных серверах.
- **Удаление данных**: В случае, если требуется отменить синхронизацию данных игрока при его следующем входе на сервер, возможно
осуществить удаление данных игрока из базы данных командой.

---

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Для одной из зависимостей требуется наличие локального артефакта плагина AsureLib. Путь до артефакта должен
выглядеть следующим образом относительно папки проекта: `../AsureLib/build/libs/AsureLib-1.0-SNAPSHOT.jar`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными или недостаточными для остальных проектов.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
